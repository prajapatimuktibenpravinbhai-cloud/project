# 🎮 Tic Tac Toe Game (0/X Game)

## 📌 About the Project
This is a simple and interactive **Tic Tac Toe (0/X) Game** built using **HTML, CSS, and JavaScript**.  
Two players can play the game and see the winner.

---

## ✨ Features

✅ Two player game  
✅ Winner announcement 🏆  
✅ Restart game option 🔄  
✅ Simple and attractive design 🎨  
✅ Easy to play  

---

## 🛠 Technologies Used

- 🌐 HTML
- 🎨 CSS
- ⚡ JavaScript

---

## ▶️ How to Play

1. Open the project folder
2. Click on **main.html**
3. Game will start in browser
4. Player X and Player O play turn by turn
5. Winner will be displayed
